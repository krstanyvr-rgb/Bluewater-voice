# Bluewater voice

This folder reads narration lines aloud for Bluewater Co videos.

It is public for one reason. GitHub runs its machines free of charge for public folders, and reading a
five minute script takes about an hour of machine time.

- `scripts/` holds the words to be read, one file per video.
- `clips/` holds the finished readings, one small sound file per line.
- The voice is Chatterbox by Resemble AI (MIT licence), using its built in default voice.

Nothing else lives here. The video engine, the business and all customer data are kept private.
